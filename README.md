# Farm Management Information System

FMIS is a web application for managing day-to-day farm operations from one workspace. It brings animal records, production data, health events, finance, inventory, tasks, and farm users together in a single operational dashboard.

## Project Output

### Dashboard

- Farm activity overview
- Animal and production summaries
- Financial and inventory indicators
- Quick access to common farm workflows

### Animal Management

- Register and edit animal information
- Store identification, breed, gender, date of birth, location, and parentage
- View a complete animal profile
- Review milk production, vaccination, health, breeding, and weight history
- Upload animal photographs
- Select existing animal names and tags while registering records

### Dairy Management

- Record morning and evening milk production
- Track total production and milk quality
- Review production history and reports

### Health and Veterinary Care

- Record vaccinations and deworming
- Track diseases, treatments, injuries, and veterinary visits
- Record next due dates and treatment outcomes

### Breeding and Reproduction

- Record artificial insemination and natural mating
- Track pregnancy status and expected calving
- Store calving and offspring information

### Finance and Inventory

- Record income and expenses
- Track customers, suppliers, and transactions
- Manage stock items, quantities, costs, and movements

### Tasks and Farm Work

- Plan work and set due dates
- Assign tasks to responsible staff
- Set task priorities and categories
- Mark work complete
- Identify pending and overdue tasks

### Users and Access

- Role-based access for farm owners, managers, workers, veterinarians, accountants, and sales staff
- Protected login and authenticated farm data

## Technology

- Next.js and React
- Material UI
- TypeScript
- PostgreSQL
- Prisma ORM
- JWT authentication
- Docker support

## Run Locally

Install the project dependencies, configure the database environment for your local machine, generate the Prisma client, and start the development server. The application is then available at `http://localhost:3000`.

The application does not publish administrator credentials. Use the private administrator values configured in your local environment.
